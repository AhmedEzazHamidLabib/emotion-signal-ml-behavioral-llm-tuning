# Emotion Signal Modeling for Behavioral Tuning of Language Models

## Overview

This project implements a framework for modeling emotion in text using a structured, continuous signal representation instead of discrete emotion labels.

Rather than predicting categories like "anger" or "joy", the system represents emotional context as a 17-dimensional signal vector capturing affective, cognitive, social, and survival-related dimensions. These signals are then used to influence downstream language model responses.

For behavioral evaluation, predicted emotional signals are used to condition responses generated by large language models, specifically GPT-4o, Grok-4.1, and Grok-3, allowing analysis of how structured emotional representations affect conversational behavior.

## Core Method

### Emotional Signal Representation

Each text input is mapped to a 17-dimensional vector with values in [0, 1], capturing:

- Affective signals (valence, arousal, energy)
- Appraisal signals (agency, controllability, uncertainty, importance)
- Social signals (proximity, warmth, exposure, assertiveness)
- Motivational signals (curiosity, novelty)
- Survival signals (threat, loss, injustice, disgust)

Signals are constructed from GoEmotions labels using prototype mappings and IDF-weighted merging.

---

## Models Implemented

- TF-IDF + Ridge Regression (baseline)
- BiGRU neural network
- DistilRoBERTa-based regressor

The goal is to predict continuous emotional signals rather than discrete labels.

---

## Behavioral Tuning Concept

Predicted signals can be used to condition large language models, enabling responses that adapt based on emotional structure rather than just surface text.

## How to Run

Install dependencies:

pip install -r requirements.txt
python dataset_annotator.py (To load and annotate datasets)


Train models:

python train_TFIDF_RR.py
python train_BIGRU.py
python train_distilroberta.py

Evaluate:

python test_roberta.py
python test_BIGRU.py
python test_TFIDF_RR.py


Run live interface:

python roberta_live_chat.py
